
# WasteZero_Infosys_Internship_Oct2025_Team_01

![Node.js CI](https://github.com/khuship003/Smartwaste-Management/actions/workflows/node.js.yml/badge.svg)

WasteZero is a digital platform to help users schedule waste pickups, categorize recyclables, and promote responsible waste management. Pickup agents are assigned intelligently based on location.



## Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **CI/CD:** GitHub Actions (Node.js)

## Getting Started

Clone the repo and run the frontend locally:

```bash
git clone https://github.com/khuship003/Smartwaste-Management.git
cd Smartwaste-Management/WasteZero_Frontend
npm install
npm start
```

## Features

- Schedule waste pickups
- Categorize recyclables
- Location-based pickup agent assignment
